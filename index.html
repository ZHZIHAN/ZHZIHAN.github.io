背景

面向脑科学科研场景，研究人员在课题设计、方法路线选择和阶段性报告撰写中，需要整合论文、技术文档、实验记录和项目材料。传统 RAG 多停留在单轮问答，难以支撑复杂科研任务拆解、证据审计和结构化报告生成。

技术方案
  • 基于 LangGraph 构建 7 节点多 Agent 工作流，覆盖意图路由、研究规划、Web 检索、本地 RAG 检索、证据裁判、分析归纳和报告生成
  • 设计 Web Search + Local RAG 双通道检索机制，融合外部公开资料与本地项目文档，提升科研问题的证据覆盖度
  • 实现 Evidence Judge 证据裁判模块，对检索证据进行去重、可信度评分、冲突审计和引用来源校验，降低大模型生成中的证据幻觉
  • 设计 Reflect 补充研究机制，当系统识别到研究背景不足、方法对照不完整或证据支撑不足时，自动生成补充检索 query 并进入下一轮检索
  • 基于 FastAPI 封装后端服务，提供同步调用接口与 SSE 流式推送接口，实时返回任务阶段、检索进度、证据审计结果和最终 Markdown 报告

系统实现了从脑科学研究问题输入到研究方案/证据分析报告生成的自动化链路，可辅助完成课题调研、方法路线比较、实验方案整理和项目材料沉淀，提升复杂科研任务的推进效率与结果可追溯性。

精神疾病研究智能知识检索系统
项目负责人  ·  2026.02 — 2026.04
背景

面向精神疾病科研团队的文献综述、诊断依据查阅和治疗方案对比场景，科研资料分散于论文数据库、临床指南、药物说明书和临床试验文档。传统关键词检索难以理解"抗抑郁药耐药性/难治性抑郁"等语义近义表达，导致文献遗漏率高、检索效率低。

技术方案
  • 设计 Hybrid Search 混合检索引擎，融合 BM25 稀疏检索与 Dense Embedding 稠密检索，基于 RRF 算法合并双路召回结果，提升精神医学术语近义表达下的召回能力
  • 引入 Cross-Encoder Rerank 精排模块，对候选论文、临床指南和药物条目进行二次相关性排序，并设计精排失败回退机制，保障检索链路稳定性
  • 基于 MCP 协议实现知识检索 Server，封装标准化 Tool，支持 Claude Desktop 等 AI Agent 直接调用私有科研知识库
  • 设计 Load → Split → Transform → Embed → Upsert 数据摄取流水线，结合 LLM 完成 Chunk 重组、元数据标注和论文结构信息保留，通过 YAML 配置支持 RAG 组件热切换
  • 建立 Ragas + Hit Rate / MRR 自动化评估闭环，构建 Golden Test Set 回归测试集，为检索策略优化提供量化依据

系统支持 500+ 篇精神疾病相关文献与指南的语义检索，Hit Rate@10 达 92%，端到端查询延迟控制在 800ms 以内，支撑科研人员和 AI Agent 双通道知识查询。
